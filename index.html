How to Play GutMove

GutMove is one complete 7-stage game. Fill all tasks across all stages before submitting the full game.

1. Open a stage
Use the Stage 1–7 tabs to move across the full motility game.
2. Pick an e-token
Drag it, or tap it once to select it.
3. Place it on a task
Drop it into the brown task slot that matches the prompt.
4. Complete all 75 tasks
The Submit Game button glows only when every required task is filled.
5. Submit once
GutMove gives one final scorecard for the full game.
6. Learn from feedback
Use Review Mistakes and the Learning Library when they unlock.
